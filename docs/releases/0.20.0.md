# Tickler 0.20.0

Released 2026-10-24, by the merge that finished it. The entries below are this
version's [changelog](../../CHANGELOG.md#0200) entries,
written alongside the changes they describe. Anything worth a longer write-up
belongs on this page, added after the fact — `docs/` is not in the published
package, so editing it later costs nothing.

- **A queue row says when its agent checks back.** Agents can now ask
  Paperclip to wake them on a task at a set time. When a row's task has one
  of these check-backs still to come, its small line ends with "agent checks
  back 14:30" (or "Tue 09:00" after today). Tickler only shows the time; it
  cannot set or change it. (PLI-330)
- **Demo mode answers its questions inline.** The demo's question rows showed
  **Reply ↗**, a link out to a thread the demo does not have; they now show
  **Answer**, and its dialog loads the question card. The Acme card asks two questions, so the "1 of 2" split is
  on show. (PLI-318)
- **The docs catch up with 0.18.0–0.19.1.** The README now mentions hiding an
  org and that paused orgs are left out; the queue guide covers approval rows
  titled by their task and the new question cards; and the queue, org-card and
  phone screenshots are regenerated to match. (PLI-317)
