# Tickler 0.20.4

Released 2026-10-24, by the merge that finished it. The entries below are this
version's [changelog](../../CHANGELOG.md#0204) entries,
written alongside the changes they describe. Anything worth a longer write-up
belongs on this page, added after the fact — `docs/` is not in the published
package, so editing it later costs nothing.

- **Tickler's worker no longer keeps an idle host awake.** Hosts that sleep
  idle instances ask each plugin worker whether it has background work, and
  one that does not answer counts as busy. Tickler's worker has none, and now
  says so. Older hosts ignore the question. (PLI-333)
